# Security

A contract that lets a web page make the application write where it should not, send
cookies where they do not belong, or download something the person did not ask for is a
security issue before any code has it. Report it privately through GitHub's
**Security → Report a vulnerability** on this repository. The organisation-wide policy is
[`.github/SECURITY.md`](https://github.com/EON-Extensible-Open-Network/.github/blob/main/SECURITY.md).
